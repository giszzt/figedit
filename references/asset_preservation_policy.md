# 素材保留策略（Asset Preservation Policy）

本文件只负责视觉对象的保留价值与重画资格。总体路线由 `routing.md` 决定，具体裁剪语义由 `asset_extraction.md` 决定，AI 背景/前景深度由 `background_reconstruction.md` 决定。

## 目的

本策略防止过度矢量化。许多位图图形含有源图专有的图标、象形图、截图、地图、缩略图、logo 或定制插画。这些对象通常应保留视觉身份，而不是被新画的 SVG 近似物替换；视觉身份不预设通过裁剪取得。

非结构性视觉对象的默认规则：

> **先保真，再判可分离性。只有窗口干净才裁剪；污染对象按编辑价值再生或压平。**

## 定义

### 结构性元素

主要功能是布局、分组或表达关系的元素：

- 面板
- 卡片
- 边框
- 标尺线和分隔线
- 网格线
- 表格边框
- 箭头和连接线
- 简单流向指示
- 背景块

结构性元素通常应重画为可编辑 SVG。

### 视觉素材

主要功能是图形身份、视觉证据、图标含义或源图专有外观的元素：

- 图形性图标
- 定制图标
- UI 截图
- 地图和遥感影像
- 照片和缩略图
- Logo 和标记
- 插入的插画
- 手绘角色或物体
- 精细图表截图
- 产品图
- 拼贴图
- 模型输出或示例图

视觉素材需要保持视觉身份，但不预设提取方法。它可以是干净源图裁剪、chroma 再生素材或清版区域中的压平对象。

## 默认决策规则

在勘察中对全部非文字视觉对象批量使用这条规则：

1. 结构性的，重画。
2. 图形性、源图专有或视觉有辨识度的，先标记为保真素材。
3. 简单通用图元，重画。
4. 对保真素材检查裁剪窗：干净才裁剪；明显污染直接分配再生或压平；只有看不清时才进入异常复核。

## 重画资格测试

视觉对象只有同时满足以下全部条件才可以重画：

- 能用少量基础 SVG 图元重建。
- 精确轮廓、纹理、明暗或图标风格不重要。
- 不是品牌/logo/源图专有象形图。
- 不是截图、地图、照片、缩略图或模型输出。
- 不含内嵌位图细节。
- 用干净 SVG 等价物替换不会改变源图观感。

任一条不满足，改为保真素材，再由裁剪窗和编辑价值决定 `crop / regenerate-chroma / flatten`。

## 强素材身份触发条件

元素具备以下任一属性时始终优先保留视觉身份，但不因此自动裁剪：

- 定制轮廓或非通用画风
- 手绘或纸纹质感
- 真实感明暗、渐变、模糊、颗粒或阴影
- 内嵌小图、缩略图、截图或地图
- 品牌标记、应用图标、机构 logo 或模型 logo
- 图形性对象：服装、人物、无人机、数据库插画、相机、文件夹、城市模型、山体模型、车辆、图表截图、手机 UI、路线图、面孔/头像
- 近似会损伤的视觉身份
- 在图中重复出现且一致性重要的源图素材

## 弱重画候选

以下内容在重画能改善可编辑性时可以重画：

- 朴素圆形、方形、矩形、圆角矩形
- 简单加减号、对勾、叉、圆点
- 简单线条箭头
- 朴素虚线框
- 简单表格/网格结构
- 只作结构标记的基础几何占位图标

## 复合元素

许多视觉区域同时含可编辑与不可编辑的子部分。

推荐拆分（图形部分仍先判可分离性）：

- 干净时裁剪图形图标或截图；污染时再生或压平
- 重打邻近标签
- 重画周边卡片或面板
- 重画连接线和箭头

例：一个含定制云图标和标签的灰色圆角图块，通常应变成：

- SVG 圆角图块
- 经可分离性判断后取得的云图标素材
- 可编辑文字标签

## AI 清版底的叠层素材

AI 清版底的完整路线与前景深度以 `background_reconstruction.md` 为准。本节只说明保素材边界：生成底板不使源图专有前景自动适合 SVG，也不要求每个前景对象都被裁回顶层。

模式 `E-ai` 的默认叠层：

- 生成的背景底板
- 可编辑文字和公式
- 重画的通用形状和简单连接线
- 只有真正需要独立源图身份的前景素材

只有三条同时成立才在底板上裁源图素材：

1. 精确源图身份重要
2. 独立移动、替换或编辑有用
3. 裁剪干净——无旧标签、引线、光晕、接缝或大块矩形原背景

移动价值低、边缘不可分离、或提取损伤比编辑性损失更显眼时，把对象压平留在清版底里。

源图素材身份的强候选包括但不限于（只有窗口干净时才裁剪）：

- 品牌、机构、产品、应用、出版方、期刊或项目标记
- 有辨识度的象形图、徽章、印章、封面标记、图例键或状态符号
- 科学符号、地图缩略图、截图、UI 片段、证据图像或领域专有小插画
- 精确风格承载身份或语义惯例的小图标
- 有纹理、明暗、抗锯齿、手绘或位图出身的标记
- 与可编辑标签配对、图标和文字可拆分的图标

优先 SVG 重画的：

- 通用分隔线、方框、简单圆点、简单箭头和布局标尺线
- 有意示意化、可用基础形状精确匹配的图标
- 源图身份不重要的占位几何

裁剪带周边背景像素时，选损伤最小的选项：

1. 移动价值低就留在清版底里
2. 局部背景与最终底板一致时才紧凑裁剪
3. 只在边缘能保持干净时移除背景
4. 只在移动重要且近似可接受并有记录时生成或 AI 清理素材

不要把生成的清版底当精确素材的来源。精确素材从原始源图裁剪。不要用大块脏源图裁剪给底板打补丁。

## 素材内嵌文字

文字融入小图标、截图或 logo 且无意编辑时，留在裁剪素材内。

文字作为可读标签或注释使用时，单独重打，只裁图形部分。

## 背景处理

裁剪视觉素材时：

- 背景是素材视觉的一部分就保留
- 只在能干净移除时移除背景
- 否则带少量周边背景裁剪，对齐到重建面板上
- 处理方式记入 manifest

对象与连续背景视觉绑定时，比较两个最终合成：提取版和压平版。提取留下光晕、破坏内部孔洞或抹掉细结构时，选压平版。

## 污染素材

被文字、引线、圆点、箭头或邻近内容穿过的对象不是干净源图裁剪。走 `contaminated_asset_recovery.md`。

独立编辑价值低或对象不可分离时用 `flatten-background`。移动重要且近似可接受时用 `regenerate-chroma`（见 `chroma_regeneration.md`）：对象复现在纯色 chroma 底上，键控为干净透明素材。不要把本地涂抹或局部 inpaint 当恢复路线。

生成的替代物必须用 `asset_fidelity: approximate-ok` 或 `semantic-only`，并带 `generation_provenance`。

## 素材清单要求

SVG 编写前从整图一次性建立素材清单。每条包括：

- 素材 ID
- 元素类型
- 源包围盒
- 目标包围盒
- 决策理由
- 裁剪 padding
- 背景处理
- 核验状态

## 禁止行为

不要：

- 用发明的通用 SVG 图标替换源图专有图标
- 仅因第一眼看着简单就重画复杂图形素材
- 不加记录地省略小图形对象
- 视觉保真是用户优先级时简化定制图标
- 重画 logo，除非用户明确要求矢量化且许可允许
- 标签应保持可编辑时把标签和图标裁在一起，除非文字不可读或已融入图标
- 把图像生成的近似物当精确源图素材呈现
- 仅因对象是 logo、地图、图表、截图、测量几何或证据图像就拒绝 AI 生成；按可达到的重建保真和候选验证来决定

## 复查问题

定稿元素决策前自问：

1. 这个对象是图表结构的一部分，还是视觉源素材？
2. 用户会期望它看起来和原图一样吗？
3. 重画会造出明显不同或通用化的替代物吗？
4. 能以可接受的 padding 精确裁剪吗（裁剪窗干净吗）？
5. 标签需要单独可编辑吗？

答案偏向"保持原始视觉保真"，就把对象批量路由为素材；具体采用 crop、regenerate-chroma 还是 flatten 由总体路线和裁剪窗决定。
